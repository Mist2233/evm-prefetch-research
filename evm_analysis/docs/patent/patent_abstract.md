# 说  明  书  摘  要

一种基于在线免推理与离线增量生成的以太坊虚拟机存储访问混合预取方法及系统，其核心思想为将机器学习推理从在线交易执行关键路径剥离为离线增量规则生成任务。在线路径仅执行 O(1) 复杂度的哈希查表，不承担任何模型推理开销；离线路径在历史数据窗口上运行 LightGBM 多标签模型，将正确预测的高频存储槽按最小支持度和单键上限过滤后，以增量规则形式合并到在线哈希表中。在以太坊主网连续 1001 个区块、约 9.4 万笔交易上的全量实验表明，离线增量管道使在线路径召回率从 22.23% 提升至 31.17%（相对提升 40.2%），存储访问总代价降低 11.3%，且召回率提升幅度随数据规模从 2000 笔至全量单调递增。该方法解决了现有单一模型在线推理开销过大与静态列表覆盖率不足的双重缺陷，适用于区块链全节点的存储预取优化场景。
