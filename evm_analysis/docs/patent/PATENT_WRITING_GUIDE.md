## 1. 文档整体结构

一份完整的专利申请由以下部分组成，**按顺序**排列：

```
┌─────────────────────────────────┐
│         说  明  书               │  ← 文档最顶部，大字标题
│         发明名称                 │  ← 居中/加粗
├─────────────────────────────────┤
│  1.  技术领域                   │
│  2.  背景技术                   │
│  3.  发明内容                   │
│  4.  技术效果                   │
│  5.  附图说明                   │
│  6.  具体实施方式               │
├─────────────────────────────────┤
│         说  明  书  附  图       │  ← 分页
│        图1 图2 图3 ...          │
├─────────────────────────────────┤
│         权  利  要  求  书       │  ← 分页
│  1. 独立权利要求                │
│  2.~N. 从属权利要求             │
├─────────────────────────────────┤
│         说  明  书  摘  要       │  ← 分页
│         [一段文字]              │
│         摘  要  附  图           │
└─────────────────────────────────┘
```

**关键原则**：
- 所有大标题（"说明书""说明书附图""权利要求书""说明书摘要"）**每个字之间加一个全角空格**：`说  明  书`、`权  利  要  求  书`
- 大标题**加粗**
- 整个文档不需要页眉页脚
- 各部分之间**分页**

| 项目 | 值 | 说明 |
|------|-----|------|
| 纸张 | A4 | 210mm × 297mm（595pt × 842pt） |
| 上边距 | ~85mm | 1080135 EMU |
| 下边距 | ~79mm | 1008380 EMU |
| 左边距 | ~79mm | 1008380 EMU |
| 右边距 | ~65mm | 828040 EMU |
| 正文字体大小 | **10.5pt** | 五号字（133350 EMU） |

## 3. 说明书（逐节详解）

### 3.1 文档开头

```
[空行]
说  明  书                          ← 加粗，22pt，居中（样例中用的是"Salutation"样式）
[空行]
发明名称                            ← 加粗，11pt，居中
[空行]
```

**发明名称规范**：
- 一般格式：`基于[技术手段]的[应用领域/目标][方法/系统]`
- 示例：
  - `基于无线信号的轮式移动目标高精度定位系统`
  - `基于区块链的去中心化AI模型优化方法`
  - `基于DAG架构的区块链设备管理和数据传输系统`
- 名称中可包含"方法及系统"（`…方法及系统`），表明同时保护方法和装置
- 名称应**反映技术领域和发明点**

---

### 3.2 技术领域

```
技术领域                              ← 加粗，独占一行
本发明涉及的是一种[领域]的技术，具体是一种[更具体的描述]。
```

**公式**：
```
本发明涉及的是一种[一级技术领域]的技术，具体是一种[精确到发明点的描述]。
```

**样例**：

| 文件 | 原文 |
|------|------|
| WheelLoc | `本发明涉及的是一种无线信号定位技术，具体是一种基于WiFi的轮式移动目标的高精度定位系统。` |
| J-3762 | `本发明涉及的是一种无线通信领域的技术，具体是一种用于移动机器人协作的自适应无线数据分享方法及系统。` |
| J-4603 | `本发明涉及的是一种大数据领域的技术，具体是一种使用区块链来完成大数据安全共享的方法及系统。` |
| J-4852 | `本发明涉及的是一种物联网领域的技术，具体是一种基于有向无环图(DAG)架构的区块链设备管理和数据传输系统，使用区块链完成物联网中安全可信的设备管理和数据传输。` |
| J-7469 | `本发明涉及的是一种神经网络领域的技术，具体是一种基于区块链的去中心化AI模型优化方法。` |

---

### 3.3 背景技术

```
背景技术                              ← 加粗，独占一行
[第1段：领域现状介绍]
[第2段：现有技术及其局限性]
[第3~N段：引证专利/文献，指出不足]
```

**标准结构模式（2~6段）**：

**第1段（可选）— 行业背景铺垫**：
- 介绍该技术领域的基本情况
- 句式：`[领域/技术]已经成为……的重要组成部分/必不可少的一部分`
- 样例：*"定位系统已经成为我们日常生活中必不可少的一部分，基于位置的服务也是我们最常用到的服务之一，如地图导航系统和增强现实游戏。"*
- **注意**：较短的可直接跳到现有技术段落，无需此铺垫

**第2段 — 现有技术及其问题**：
- 句式：`现有的/传统的[技术]通常使用[方法A]、[方法B]等方法。但……存在以下不足/局限性：……`
- 关键词：`现有`、`传统`、`通常`、`然而`、`但`、`局限性`、`无法`、`容易受到`、`难以`
- 样例：*"现有的Wi-Fi的定位技术通常使用基于接收信号强度指示的三角测量、信号到达时间和到达角度估算等方法进行定位。但几乎所有定位方法都是针对Wi-Fi信号的物理层信息……却没有任何相关工作关注于移动目标本身。"*

**第3段 — 引证专利/文献**：
- 引证专利专用句式：
  ```
  经过对现有相关领域的检索/对现有技术的检索发现，中国专利文献号CNXXXXXXXXXX，公开日期为20XX年X月X日，公开了一种[技术名称]。该发明[简述技术方案]。但该技术[指出不足]。
  ```
  或：
  ```
  中国专利公开号CNXXXXXXXXXX，公开日期为20XX年X月X日，公开了一种[技术名称]。[简述]。[这种方法的缺点在于……]。
  ```
- 建议引证 **2~3 篇** 相关专利
- 引证文献后必须指出其**不足之处**

---

### 3.4 发明内容

```
发明内容                              ← 加粗，独占一行
[第1段：问题陈述+解决方案]
本发明通过以下技术方案实现的：          ← 固定引导句
[第2段：技术方案的总体描述]
[第3段起：分层详述]
```

**第1段 — 核心公式**：
```
本发明针对[现有技术的不足/缺陷]（或：针对现有技术存在的上述不足），提出[发明名称/方案]，[方案的核心工作原理/效果简述]。
```

**样例**：
- *"本发明针对现有物联网过分依赖安全引擎以及系统扩展性较低的缺陷，提出一种基于DAG架构的区块链设备管理和数据传输系统，具有更高的交易效率且能够显著降低区块链共识机制的计算复杂度，使区块链技术能够适用于物联网设备。"*
- *"本发明针对现有定位技术的不足，根据对大多数移动目标使用车轮移动的观察，充分利用车轮旋转的优势，提出了一种基于无线信号的轮式移动目标高精度定位系统，通过与车轮一同旋转的天线，利用惯性传感器描绘出天线的运动轨迹，构建出大规模的天线阵列，计算Wi-Fi信号的到达时间和到达角度，进而实现对轮式移动目标的高精度定位。"*

**方案引导句 — 固定**：
```
本发明是通过以下技术方案实现的：
```

**第2段 — 总体技术方案**：
```
本发明涉及一种[系统/方法]，[系统构成/方法步骤概要]。
```

如果是系统类：
```
本发明涉及一种[系统名称]，包括：[模块A]、[模块B]、[模块C]，其中：
- 模块A用于……；
- 模块B用于……；
- 模块C用于……。
```

如果是方法类：
```
本发明涉及一种[方法名称]，[步骤概要叙述]。
```

**后续段落（"分层次描述"）**：
- 用 **`所述的[术语]是指：`** 句式展开详细定义
- 可嵌套引用：`如权利要求N所述的……`
- 涉及公式时直接写入正文，式后有编号
- 方法步骤可以用编号列出（1、2、3…或1.1、1.2…等）

---

### 3.5 技术效果

```
技术效果                              ← 加粗，独占一行
与现有技术相比，本发明[具体有益效果]。
```

**公式**：
```
与现有技术相比，本发明[优点1]；进一步地/同时，[优点2]。
```

**常用表达**：
- `与现有技术相比，本发明……`
- `本发明充分利用了[技术特点]`
- `有效解决/克服/避免了……`
- `保证了/实现了……`

**样例**：
- *"与现有技术相比，本发明充分利用了车轮旋转的特点，提出了一种用于轮式移动目标的基于WiFi的高精度定位系统，在室内、室外平坦路面和室外颠簸路面三种环境下，其定位精度均可达到1米以内。"*
- *"与现有技术相比，本发明具有高度匿名化……通过使用区块链技术，本发明有效杜绝了数据共享平台易受分布式拒绝攻击(DDOS)、女巫攻击(Sybil attacks)的安全隐患。"*

---

### 3.6 附图说明

```
附图说明                              ← 加粗，独占一行
图1：本发明的[名称]结构示意图。
图2：本发明的[某流程/结构]示意图。
图3：……
……
```
或简洁写法：
```
附图说明
图1
图2
图3
……
```

### 3.7 具体实施方式

```
具体实施方式                            ← 加粗，独占一行
[详细展开技术方案的实施细节]
```

**写法要点**：
1. **与发明内容呼应**：具体实施方式应完整覆盖权利要求中的所有技术特征
2. **引用附图**：`如图X所示，……`
3. **详细量化**：给出具体参数、数值、实现细节
4. **可多实施例**：可以有多个实施方式/实施例

**常用句型**：
- `如图X所示，本发明的[模块/步骤]……`
- `具体地，……`
- `进一步地，……`
- `优选地，……`
- `所述的[部件/步骤]具体是指：……`

## 4. 权利要求书

### 4.1 整体格式

```
权  利  要  求  书                      ← 分页，加粗大字标题
[空行]
1、[独立权利要求]
[空行]
2、[从属权利要求]
[空行]
3、[从属权利要求]
……
```

### 4.2 权利要求编号规则

- 使用 `1、` `2、` `3、` 的中文编号格式（注意是中文顿号，不是英文句点）
- 每项权利要求之间**空一行**
- 权利要求末尾**不加句号**

### 4.3 独立权利要求

**方法类独立权利要求**：
```
1、一种[方法名称]，其特征在于，[步骤A]；[步骤B]；[步骤C]。
```

**系统/装置类独立权利要求**：
```
1、一种[系统/装置名称]，其特征在于，包括：[模块A]、[模块B]、[模块C]，其中：
[模块A用于……]；
[模块B用于……]；
[模块C用于……]。
```

**公式**：
```
1、一种[发明名称]，其特征在于，[核心技术特征的描述]。
```

### 4.4 从属权利要求

```
N、根据权利要求M所述的[引用主题]，其特征是，[附加技术特征]。
```

**引用格式**：
- 单引用：`根据权利要求M所述的……`
- 多引用：`根据权利要求M~N中任一所述的……` 或 `根据权利要求M或N所述的……`

### 4.5 权利要求撰写要点

- **独立权利要求**写入**必要技术特征**，范围最宽
- **从属权利要求**逐步增加限定，形成退路
- 使用 `其特征是` 或 `其特征在于` 作为特征分界词
- 方法权利要求按**时间顺序**描述步骤
- 系统权利要求按**模块构成**描述
- 系统权利要求的方法实施例可单列一条：`一种基于上述任一权利要求所述系统的[方法]，其特征在于，……`

## 5. 说明书摘要

```
说  明  书  摘  要                      ← 分页，加粗大字标题
[一段文字，不超过300字，概述发明内容]
[空行]
摘  要  附  图                          ← 标注摘要附图编号（可选，如只有文字摘要可省略）
```

**摘要写法**：
```
一种[发明名称]，[核心工作原理一句话]。为了应对[问题/需求]，本发明提出了[技术方案概述，包含主要模块/步骤]。[有益效果]。
```

**样例**：
- *"一种用于轮式移动目标的基于WiFi的高精度定位系统，其基本思想为让天线与车轮一同旋转，利用惯性传感器描绘出天线的运动轨迹，构建出大规模的天线阵列，计算WiFi信号的到达时间和到达角度，进而实现对轮式移动目标的高精度定位。"*

```

```

## 8. 审查意见警示

部分样例文档开头附有**专利局审查意见的提醒**，这些内容**不是申请书正文的一部分**，而是导师/代理机构加的批注意见。需要注意避免以下被认为"不具创造性"的情形：

### 常见拒绝理由

```
【将多个已知技术进行常规组合得到的叠加多个已知功能的技术方案
从专利法角度判断不视为具有创造性，包括：
- 组合多个已知操作手段、算法、模组
- 混合多种已知物质
- 将已知操作替换应用场景
从而实现已知功能的组合】
```

### 数据处理类专利的特殊要求

处理数据的方法/系统如满足以下条件**可能授权**：
1. **针对的对象**（数据背后具体含义）为客观属性
2. **处理过程存在创新**
3. 不涉及"以获得疾病治疗诊断结果为最终目的"

**不能授权的情形**：
- 方法以确诊患病为最终目的 → 属于诊断方法，不能授权
- 数据为主观量表/社会科学范畴 → 不是技术方案
- 处理手段均为现有技术 → 不具创造性

### 对策

撰写时要特别注意：
- **发明点不能只是"组合现有技术"**，必须有**独创的技术手段**
- 对于 AI/数据处理类专利，强调**技术层面的创新**（性能提升、计算效率、架构改进），而不是功能组合
- 如果有实际**效果数据**（精度提升 X%、速度提升 Y 倍），写入技术效果部分

## 9. 完整组装清单

### 最终文档顺序
