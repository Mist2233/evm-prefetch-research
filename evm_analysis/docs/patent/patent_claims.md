# 权  利  要  求  书

1、一种基于在线免推理与离线增量生成的以太坊虚拟机存储访问混合预取方法，其特征在于，包括以下步骤：

步骤一、以交易的目标合约地址和函数选择器构成的二元组作为规则键，在训练数据集上对每个规则键收集其所有交易中出现的存储槽并去重，得到历史并集；将历史并集大小不超过预设阈值的规则键及其对应存储槽列表写入快路径哈希表；对历史并集大小超过预设阈值的规则键，使用训练数据中属于该类键的样本训练一个多标签分类模型作为慢路径预测器；

步骤二、在线推理时，对于输入的待处理交易，若其规则键在快路径哈希表中命中，则直接返回对应存储槽列表作为预测结果；若未命中，可选择不返回任何预测或返回空列表，以避免引入实时推理延迟；

步骤三、将链上数据按区块号切分为第一时间窗口和第二时间窗口；在第一时间窗口上，对快路径哈希表中不存在的规则键对应的交易，调用慢路径多标签分类模型进行预测，取预测存储槽集合与所述交易真实访问的存储槽集合的交集作为正确预测槽，并按规则键聚合各存储槽的正确次数，得到候选增量字典；

步骤四、对候选增量字典施加最小支持度过滤和单键新增上限过滤，保留正确次数不低于最小支持度且排序后不超过单键新增上限数量的存储槽，将过滤后的存储槽合并到快路径哈希表中，得到增强哈希表；

步骤五、在第二时间窗口上，分别使用原始哈希表和增强哈希表进行仿真评估，对比召回率、精度和总访问代价中的至少一项指标，其中召回率为预取防止的块内首次缺失次数与无预取时应有首次缺失总数的比值。

2、根据权利要求1所述的方法，其特征是，所述多标签分类模型为 LightGBM 模型，其输入特征包括：目标合约地址的标签编码、合约代码哈希的标签编码、函数选择器的标签编码、调用数据前三个参数的标签编码、发送方地址的标签编码以及交易金额的标签编码。

3、根据权利要求1所述的方法，其特征是，步骤一中所述历史并集阈值是可调节参数，通过扫描该阈值可在快路径查表覆盖率与慢路径模型推理精度之间形成 Pareto 前沿。

4、根据权利要求1所述的方法，其特征是，步骤四中所述最小支持度参数确保只有被慢路径模型在多个不同交易中反复正确预测的存储槽才被纳入增量规则。

5、根据权利要求1所述的方法，其特征是，步骤四中所述单键新增上限参数控制每个规则键最多新增的存储槽数量，按正确次数降序选取。

6、根据权利要求1所述的方法，其特征是，步骤五中所述仿真评估包括模拟块内首次访问语义：每个区块开始前清空缓存集合，对块内每笔交易，先将预测存储槽集合注入缓存，再按真实访问序列逐个计费——已在缓存中的计为命中，不在缓存中的计为缺失并将该存储槽加入缓存；块内重复访问同一存储槽后续均为命中。

7、根据权利要求1所述的方法，其特征是，还包括一个执行时间覆盖评估步骤：引入覆盖比例参数 alpha，计算有效预测开销 = max(0, 原始预测开销 − alpha × 交易执行总时间)，以及覆盖后净收益 = 存储代价节省量 − 有效预测开销，通过扫描 alpha 值确定在线慢路径方案转正的可行性边界。

8、根据权利要求7所述的方法，其特征是，所述交易执行总时间由单笔交易执行时间代理累加得到，单笔代理为 len(accessed_slots) × 单槽执行时间因子 + 基础执行时间常数。

9、一种基于在线免推理与离线增量生成的以太坊虚拟机存储访问混合预取系统，其特征在于，包括：

数据加载模块，用于读取链上交易 trace 数据并按真实区块号或伪块窗口分组，数据包含目标合约地址、函数选择器、合约代码哈希和真实访问存储槽列表字段；

混合预取器模块，包含快路径哈希表和慢路径多标签分类模型，对外提供统一的批量预测接口，快路径命中时直接返回哈希表对应条目，未命中时调用慢路径模型或返回空列表；

缓存仿真器模块，用于模拟块内首次访问语义，在每个区块开始前清空缓存集合，按交易真实访问序列计费并统计命中与缺失次数；

离线增量管道模块，用于执行时间窗口切分、在第一时间窗口上对未命中交易调用慢路径模型生成候选存储槽、按最小支持度和单键新增上限过滤候选存储槽、以及将过滤后的存储槽合并到快路径哈希表中；

指标聚合模块，用于汇总仿真运行结果并计算召回率、精度和加速比指标。

10、根据权利要求9所述的系统，其特征是，所述离线增量管道模块在生成候选存储槽时，仅对快路径哈希表中不存在的规则键调用慢路径多标签分类模型，已存在的规则键直接跳过以节省计算资源。
