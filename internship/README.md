## 编译方法

周记使用 ctex 文档类，需要 TeX Live / MacTeX / Overleaf 等发行版。

```bash
cd internship/weekly
xelatex week1.tex     # 各篇单独编译，week2 - week4 同理
```

模板将正文字体设置为小四（`\zihao{-4}`），文档类声明了 `fontset=fandol`，
TeX Live 自带 Fandol 字体，Windows / macOS / Linux / Overleaf 均可直接编译。
若本机没有 Fandol 字体而编译报错，把 `weekN.tex` 首行的 `fontset=fandol`
删掉即可，ctex 会自动改用系统默认中文字体。
